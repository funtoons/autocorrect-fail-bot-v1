Entry for the [Funniest Autocorrect Fail](https://make.fun/c/u-zeroxfive-funniest-autocorrect-fail-ddf82154) competition on [make.fun](https://make.fun).

`main.py` (Python standard library only, deterministic, offline) writes a
single original autocorrect-fail line — under 200 characters — to
`/output/entry.txt`.

Run it with:

```sh
python3 main.py
```
